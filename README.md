# RiskiMobility - Sistem Manajemen Penyewaan Kendaraan

Aplikasi web manajemen penyewaan kendaraan berbasis **Laravel** dengan arsitektur MVC.

## Fitur Utama
- Manajemen data pelanggan, kendaraan, dan transaksi sewa (CRUD)
- Validasi input data transaksi
- Struktur database relasional menggunakan Laravel Migrations

## Teknologi
- PHP & Laravel Framework
- Blade Template Engine
- MySQL
